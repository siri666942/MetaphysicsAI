## 二、数据库相关（改库必看）

### 1. 数据库文件位置

| 环境 | 路径 |
|------|------|
| **生产（Docker）** | `/root/sites/beingecho.tech/data/chat_history.db` |
| 本地开发（默认） | `backend/chat_history.db` |

- Docker 启动时用 `-v /root/sites/beingecho.tech/data:/app/data`，环境变量 `DATABASE_PATH=/app/data/chat_history.db`
- 改生产库时，直接操作 `data/chat_history.db`

### 2. 表结构（来自 `backend/database.py`）

```
users
├── id              TEXT PRIMARY KEY     # UUID
├── username        TEXT NOT NULL UNIQUE # 用户名
├── password_hash   TEXT NOT NULL       # Werkzeug 的 pbkdf2:sha256 哈希
└── created_at     TEXT NOT NULL       # ISO 格式时间

conversations
├── id              TEXT PRIMARY KEY     # UUID
├── title           TEXT NOT NULL       # 默认 '新对话'
├── user_id         TEXT                # 外键 → users.id，可为空
├── created_at      TEXT NOT NULL
└── updated_at      TEXT NOT NULL

messages
├── id              INTEGER PRIMARY KEY AUTOINCREMENT
├── conversation_id TEXT NOT NULL      # 外键 → conversations.id，级联删除
├── role            TEXT NOT NULL       # 'user' 或 'assistant'
├── content         TEXT NOT NULL
└── created_at      TEXT NOT NULL
```

### 3. 密码哈希

- 使用 `werkzeug.security.generate_password_hash`，默认方法 `pbkdf2:sha256`
- **不能直接写明文**，必须用 Python 生成哈希后再写入

生成新密码哈希的 Python 片段（在项目目录下执行）：

```python
from werkzeug.security import generate_password_hash
print(generate_password_hash("你的新密码"))
```

### 4. 常用 SQL 示例

```sql
-- 查看所有用户
SELECT id, username, created_at FROM users;

-- 改用户名（例如 s → Siri）
UPDATE users SET username = 'Siri' WHERE username = 's';

-- 改密码（需先用 Python 生成 password_hash，再替换下面的 xxx）
UPDATE users SET password_hash = 'pbkdf2:sha256:600000$...' WHERE username = 'Siri';

-- 查看某用户的对话
SELECT c.id, c.title, c.updated_at FROM conversations c
JOIN users u ON c.user_id = u.id WHERE u.username = 'Siri';

-- 查看某对话的消息数
SELECT conversation_id, COUNT(*) FROM messages GROUP BY conversation_id;
```

## 三、改库操作方式

### 方式 A：命令行 sqlite3（服务器已安装时）

```bash
sqlite3 /root/sites/beingecho.tech/data/chat_history.db
```

### 方式 B：Python 脚本（推荐，可生成密码哈希）

```bash
cd /root/sites/beingecho.tech
python3 -c "
import sqlite3
from werkzeug.security import generate_password_hash

db = 'data/chat_history.db'
conn = sqlite3.connect(db)
c = conn.cursor()

# 例：把 s 改成 Siri，密码改为 @sunrui2025
new_hash = generate_password_hash('@sunrui2025')
c.execute(\"UPDATE users SET username='Siri', password_hash=? WHERE username='s'\", (new_hash,))
conn.commit()
print('Done')
conn.close()
"
```

### 方式 C：图形化工具

- 把 `data/chat_history.db` 下载到本地
- 用 DB Browser for SQLite、DBeaver、Navicat 等打开编辑

## 四、改完数据库后

- 若只改了 `users` 表：**不需要**重启容器，立刻生效
- 若改了表结构或不确定：执行 `docker restart beingecho-app` 更稳妥
